# Phase 3: Emotional Contagion — Design Document

**Date:** 2026-02-28
**Status:** Approved
**Scope:** Contagion + decay + prompt injection + UI. Scorer effects (impulsivity, withdrawal) deferred to Phase 4.

---

## Overview

Add a continuous emotional state to each agent using Russell's circumplex model. Emotions are generated by actions and conversations, transfer between nearby agents via proximity-based contagion, decay toward a per-character baseline over time, and inject into LLM conversation prompts to color dialogue.

## Emotion Model

### Circumplex (2D continuous)

- **Valence**: -1.0 (miserable) to +1.0 (joyful) — how pleasant the experience is
- **Arousal**: -1.0 (lethargic) to +1.0 (agitated) — how activated the agent is

Both axes are -1 to +1 (not 0 to 1 for arousal). This allows representing deactivated states like boredom (-0.2, -0.6) with full resolution.

### Emotion Anchors (for label mapping)

10 anchor points distributed around the circumplex. Label assignment uses Euclidean nearest-neighbor lookup.

| Label | Valence | Arousal |
|-------|---------|---------|
| excited | 0.8 | 0.7 |
| happy | 0.7 | 0.3 |
| content | 0.5 | -0.3 |
| calm | 0.3 | -0.6 |
| bored | -0.2 | -0.6 |
| sad | -0.6 | -0.4 |
| stressed | -0.5 | 0.5 |
| angry | -0.7 | 0.7 |
| afraid | -0.6 | 0.8 |
| neutral | 0.0 | 0.0 |

Near-neutral emotions (distance < 0.15 from (0,0)) are omitted from prompts to reduce noise. Intensity descriptors: "slightly" (distance 0.15–0.4), no prefix (0.4–0.7), "very" (>0.7).

### Character Emotional Profiles

| Trait | Alex | Maya | Default |
|-------|------|------|---------|
| Baseline valence | 0.15 | 0.0 | 0.0 |
| Baseline arousal | 0.05 | -0.05 | 0.0 |

## Emotion Sources

### Action effects (on action completion)

Each action declares optional emotional effects in the action registry as `emotionalEffects: { valence: number, arousal: number }`. These are additive deltas, clamped to [-1, +1] after application.

| Action category | dValence | dArousal | Rationale |
|-----------------|----------|----------|-----------|
| eat_at_home, eat_at_cafe | +0.15 | -0.1 | Satisfaction + calm |
| socialize_at_cafe | +0.2 | +0.1 | Enjoyment + mild energy |
| nap_at_home, rest_at_park | +0.1 | -0.2 | Comfort + relaxation |
| read_at_home | +0.1 | -0.15 | Contentment + calm |
| exercise_at_park | +0.15 | +0.2 | Endorphins + activation |
| people_watch | +0.05 | -0.1 | Mild pleasure + calm |
| cook_at_home | +0.2 | +0.05 | Creative satisfaction |
| gossip_at_cafe | +0.1 | +0.15 | Social energy + stimulation |
| eavesdrop | -0.05 | +0.15 | Slight guilt + tension |
| skip_plans | -0.1 | -0.1 | Guilt + deflation |
| chat_with_nearby | +0.15 | +0.1 | Social pleasure |

### Conversation outcome effects (on conversation end)

Piggybacking on existing `InteractionOutcome` in `agentRememberConversation`, same as opinions:

| Outcome | dValence | dArousal |
|---------|----------|----------|
| positive_social | +0.2 | +0.1 |
| negative_social | -0.3 | +0.2 |
| helpful | +0.15 | +0.05 |
| betrayal | -0.5 | +0.4 |
| impressive | +0.3 | +0.2 |
| neutral | 0 | 0 |

### Critical need effects (during need depletion)

When a need crosses its critical threshold: valence -0.3, arousal +0.3 (distress + urgency). Applied once per crossing, not continuously.

## Decay

Exponential decay toward per-character baseline with separate half-lives:

```
current = baseline + (current - baseline) × 2^(-elapsed / halfLife)
```

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| Valence half-life | 120 game-minutes | ~2 real hours. Matches Sentipolis. Mood lingers. |
| Arousal half-life | 60 game-minutes | ~1 real hour. You calm down faster than you cheer up. |

Decay runs in `agentDoSomething` alongside need depletion, using the same elapsed-time calculation.

## Contagion

### Transfer formula

```typescript
function transferEmotion(sender, receiver, distance, maxDistance, closeness, receptivity, charisma) {
  if (distance > maxDistance) return { dValence: 0, dArousal: 0 };

  const proximityWeight = 1 - (distance / maxDistance);
  const transferStrength = proximityWeight * closeness * receptivity * charisma * CONTAGION_SCALE;

  return {
    dValence: (sender.valence - receiver.valence) * transferStrength,
    dArousal: (sender.arousal - receiver.arousal) * transferStrength,
  };
}
```

### Parameters

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| Max contagion distance | 10 tiles | Roughly "same zone" on 48x31 map |
| CONTAGION_SCALE | 0.1 | Prevents instant sync. Gradual convergence over many ticks. |

### Relationship closeness derivation

`closeness = (normalize(trust) + normalize(affinity) + normalize(familiarity)) / 3`

Where normalize maps [-100..100] to [0..1] for trust/affinity, and [0..100] to [0..1] for familiarity. Strangers (no relationship) use closeness = 0.2 (mild background contagion).

### Integration point

Runs in `agentDoSomething` after need depletion (Step 2), before action scoring (Step 4):
1. Fetch this agent's emotional state (lazy-init from character baseline)
2. Apply decay for elapsed time
3. For each agent in `otherFreePlayers` within max distance, fetch their emotional state and compute transfer delta
4. Sum all deltas, apply to current state, clamp [-1, +1]
5. Persist updated state

## Prompt Injection

Same pattern as opinions. Helper function `emotionPrompt(emotionDoc)` returns lines like:
- "You're currently feeling excited and energetic."
- "You're feeling slightly sad."
- Near-neutral: omitted entirely.

Added to all 3 conversation prompt builders (start, continue, leave) via `queryPromptData`.

## PsychePanel UI

### Emotion indicator

A 2D dot plot showing the agent's position on the circumplex:
- X-axis: valence (-1 to +1)
- Y-axis: arousal (-1 to +1)
- Dot color: green (positive valence) / red (negative valence)
- Label text below: current emotion label + intensity
- Quadrant labels in corners: "excited", "stressed", "calm", "sad"

Section placed between Opinions and Relationships.

## What's Deferred

- **Scorer effects** (Phase 4): high arousal → impulsivity bonus, low valence → social withdrawal penalty
- **Critical-need emotional spike**: needs Phase 4 tick integration to detect threshold crossings during depletion
- **Mood layer**: long-term emotional integration. Not needed with 2 agents — half-life decay is sufficient.
- **Dominance axis**: the 3rd PAD dimension. Relationship system (trust/respect) already covers power dynamics.
